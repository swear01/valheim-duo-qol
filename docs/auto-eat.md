# 自動續吃

v56 加入 [Hunger Pangs 1.3.3](https://thunderstore.io/c/valheim/p/DrummerCraig/Hunger_Pangs/)。先手動吃好想用的食物，並在身上保留同種備品；食物剩餘時間降至 25% 時會自動續吃同一種，正常消耗庫存。20 分鐘的食物會在約剩 5 分鐘時續吃。

v57 開啟死亡保留食物：復活後保留已吃食物的效果與剩餘時間；TimeControl 時間連動也已開啟。包內未安裝 TimeControl，因此目前不改變食物時間；日後若安裝，食物時間會跟著它的晝夜倍率調整。工作台／船上暫停計時與四種自動喝藥仍關閉。

食物可先放 ExtraSlots 的食物專用格；模組從玩家背包尋找同種食物。格子內續吃、死亡後保留與 TimeControl 連動尚未在遊戲內實測。

兩人匯入同一份 v60 私人包為新 profile，勾選 Import all files。Hunger Pangs 的主機會檢查連線玩家是否裝有相同版本。
