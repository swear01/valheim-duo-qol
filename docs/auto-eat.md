# 自動續吃

v56 加入 [Hunger Pangs 1.3.3](https://thunderstore.io/c/valheim/p/DrummerCraig/Hunger_Pangs/)。先手動吃好想用的食物，並在身上保留同種備品；食物剩餘時間降至 25% 時會自動續吃同一種，正常消耗庫存。20 分鐘的食物會在約剩 5 分鐘時續吃。

已關閉工作台／船上暫停食物計時、四種自動喝藥、死亡保留食物效果與 TimeControl 時間倍率，保留原版食物規則。食物可先放 ExtraSlots 的食物專用格；模組從玩家背包尋找同種食物，格子內實際續吃行為尚未實測。

兩人匯入同一份 v56 私人包為新 profile，勾選 Import all files。Hunger Pangs 的主機會檢查連線玩家是否裝有相同版本。
