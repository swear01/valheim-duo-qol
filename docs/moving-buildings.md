# 搬移建築

v36 加入 [MovingDay 1.1.0](https://thunderstore.io/c/valheim/p/DrakosDJ/MovingDay/)。它搬移既有建築物件，可保留箱內物品；不需要 PrefabHammer 或 Infinity Hammer。

## 操作

1. 備份世界，先在測試世界搬小房子；兩人使用相同最新版 profile。
2. 拿建築槌，瞄準一塊建材：`G` 選取／取消單件，`H` 選取相連建築。檢查綠色高亮是否包含所有需要的建材，也有沒有選到旁邊房子；可用 `G` 增減選取。
3. 兩人離開選取建材周圍至少 3 公尺，關閉箱子。箱內有金屬等不可傳送物品時，先搬出這些物品；安全檢查會阻止搬移，即使目的地只在旁邊。
4. 留在舊家附近按 `L`，進入搬移預覽；須在離開來源區域前進入此模式。滾輪旋轉，方向鍵上下或 `Alt＋滾輪` 調高度，`Home` 貼齊瞄準表面，`Shift` 可微調。
5. 需要保留整地或地下室時，選擇與舊址地形範圍不重疊的目的地；按住**左 Ctrl** 檢視預覽，保持按住再按左鍵確認，會在新址套用地形並恢復舊址地形。不按 Ctrl 則只搬建築，目的地須已有合適地基。右鍵或 `Esc` 取消。`Shift＋G/H` 或瞄準空處按 `G/H` 清空選取。搬完等待支撐重新計算，檢查地基、屋頂、箱內物品、床與傳送門，再存檔、退出並重載，讓另一名玩家確認。

## 本包設定

- 保留玩家、使用中箱子與不可傳送物品的阻擋檢查。
- `TerrainModifierKey = LeftControl`：v37 恢復作者預設。平時只搬建築；放置時按住左 Ctrl，才連整地／挖掘一起搬移並恢復舊址地形。
- `MoveTamedAnimals = false`：不自動搬走附近馴養動物。
- `G/H/L` 等其他按鍵沿用作者預設，可在 ConfigurationManager（F10）調整 `com.drakosdj.movingday.cfg`。

目前只設定以上限制；模組仍可跨區搬建築，沒有加入自訂搬運費用或距離上限。搬移時先關閉建築攝影機，再使用 MovingDay，避免同時操作同一個建築預覽。

地形模式適合依賴整地或地下室的房子；只搬建築到不匹配的地面可能失去支撐。但連地形搬移也不保證完整保留支撐：模組只搬它捕捉到的地形修改，且目的地高度調整有上限。它先套用新址再復原舊址，因此目的地須避開舊址地形範圍，並確認沒有影響附近未選取的建築。先用世界備份測試，再檢查地基與屋頂。

MovingDay 對剛搬移的已載入建材暫時保護支撐判定約 5 秒，再恢復正常計算；不會永久增加材料支撐力。不要用管理員清理命令 `mdclean` 搬家，該命令會刪除世界物件。

## 驗證範圍

已核對公開 ZIP CRC、路徑、manifest、依賴與 DLL 雜湊，並從 1.1.0 DLL 核對 GUID、設定綁定、左 Ctrl 啟用地形鍵與「新址套用、舊址復原」順序、金屬／箱子／玩家阻擋與搬移／支撐程式路徑。v37 的 47 個套件版本與內附 DLL 不變，38 份設定只有 MovingDay 的地形快捷鍵變更；其他 37 份設定逐位元組保留。
