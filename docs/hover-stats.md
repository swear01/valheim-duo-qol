# 建材與船身數字

v35 加入 [AzuHoverStats 1.1.11](https://valheim.hexium.gg/mods/Azumatt/AzuHoverStats)。拿槌子選修理模式，靠近並指向建材，顯示「耐久 目前／最大值（百分比）」與「支撐 目前／最大值（百分比）」。補柱前後比較同一塊屋頂的支撐數字，等遊戲更新支撐後再判讀。

支撐百分比是該材質上限的比例，不是倒塌機率。不同材質的數字與倒塌下限不同，不能只用百分比比較承載能力。

看船時同樣拿槌子指向船身，查看耐久數字；船的支撐列不作為船體受損判斷。修船需在工作台範圍內，以槌子的修理工具點船身。握舵航行時沒有常駐船況儀表。

本包保留原版顏色，只開建材數字；額外物品提示、箱子內容與倒數均關閉，沒有新增切換快捷鍵。可用既有 ConfigurationManager（F10）調整 `profile/BepInEx/config/Azumatt.AzuHoverStats.cfg` 對應的遊戲設定。

AzuHoverStats 是客戶端資訊顯示模組，只需想顯示的玩家安裝。它不調整建材強度、船生命值上限或修理規則。
